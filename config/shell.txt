@shellPath ../cadroid
cadroid 项目的路径（相对本仓库或绝对路径都可以）
例：Windows  C:\Users\你\StudioProjects\cadroid
    Linux    /home/你/StudioProjects/cadroid

@buildToolPath /path/to/Android/Sdk/build-tools/34.0.0
Android SDK Build Tools 目录，用于 shellAlignApk(zipalign) 与 shellSignApk(apksigner)。
必须是已安装的版本目录，例如：C:\Users\你\AppData\Local\Android\Sdk\build-tools\34.0.0

# 若命令行环境里没有 java（PATH 中找不到，Android Studio 自带的 jbr 也行），
# 指定一个 JDK 目录，构建时会写入 JAVA_HOME 并把它的 bin 加进 PATH
# @javaHome /path/to/jdk-17

@dexPath ./app/build/intermediates/dex/release/minifyReleaseWithR8/classes.dex
Gradle 构建出的 classes.dex 路径。这个 dex 的 CRC32 会写进脚本，运行时校验（$dexCrc$）。
AGP 8：release 经 R8 精简，产物在 dex/release/minifyReleaseWithR8/ 下；
AGP 7.3 及更早为 dex/release/mergeDexRelease/out/classes.dex。

@releaseSignPath ./app/signatures/release.signature
正式版签名公钥文件。内容必须是签名证书的 DER 字节（不是 PEM 文本），
因为它被当作异或密钥使用，运行时用的是 PackageManager 返回的 Signature 字节数组。
若做过 v3 密钥轮换：这里必须保持为 lineage 里最老那张证书的 DER
（实测 apksigner 带 --lineage 签名后，API<24 与 24~32 用最老的密钥，33+ 才换成新密钥）。

@debugSignPath ./app/signatures/debug.signature
调试版签名公钥文件。同样必须是证书 DER，且必须与 debug 包实际签名用的密钥一致。

@hotfixPrivateKey ./app/signatures/privateKey.pem
热更新签名私钥，对应 cadroid 里 Secret.getVerifyKey() 返回的公钥。

@keystorePath ./app/signatures/release.keystore
签名文件路径（alias: testkey）

@keyPasswordPath ./app/signatures/release.password
密钥密码文件

@lineagePath ./app/signatures/release.lineage
密钥轮换用的 lineage 文件（apksigner rotate 生成）。默认不存在 = 普通单密钥签名。
轮换步骤：
  1) 生成新密钥：keytool -genkeypair -keystore app/signatures/new.keystore -alias newkey ...
  2) 生成 lineage：
     apksigner rotate --out app/signatures/release.lineage \
       --old-signer --ks app/signatures/release.keystore --ks-key-alias testkey \
                    --ks-pass file:app/signatures/release.password \
       --new-signer --ks app/signatures/new.keystore --ks-key-alias newkey \
                    --ks-pass file:app/signatures/new.password
  3) 填好下面的 lineageSigners（从旧到新），之后 shellBuildRelease 会自动带 --lineage 签名
  4) 若改用新密钥加密脚本（不推荐），记得 33+ 能解、24~32 解不开

@lineageSigners []
密钥轮换时按【从旧到新】列出 lineage 里每把密钥，留空数组 = 用 keystorePath 单密钥签名。
注意：readConfig 是按行解析的，跨行的值必须写成块（下面 lineageSignersExample 就是块写法示例，
启用时把它的键名改成 lineageSigners 并把上面的 [] 删掉）：
@lineageSignersExample
[{"keystorePath":"./app/signatures/release.keystore","alias":"testkey","passwordPath":"./app/signatures/release.password"},
 {"keystorePath":"./app/signatures/new.keystore","alias":"newkey","passwordPath":"./app/signatures/new.password"}]
@end lineageSignersExample
